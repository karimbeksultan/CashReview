- Use cash-review-wordmark.svg on light surfaces and cash-review-wordmark-inverse.svg on dark surfaces.
- Use cash-review-mark.svg for the primary mark and cash-review-mark-inverse.svg on dark surfaces.
- favicon.svg adds the white mark to a plum rounded square.
- readme-header.svg places the inverse wordmark on a self-contained plum background for the repository header.
