# Review workflow check

Start the prepared local service, open the workspace, and confirm its runtime status. Use the marked synthetic preview for interface demonstrations without displaying private recordings.

For an authorized real recording: choose the MOV, start analysis, follow progress and stop on a completed result or explicit failure. Inspect the large model summary, play the original sequence around each timestamp, and open source evidence at full size. Use arrow keys to move between frames, Escape to close, and the video-jump control to inspect context.

Record **Confirm concern**, **No concern**, or **Needs more review**, add the reason in the notes field, and save. Confirm the saved state is visible. This is a separate human decision; the model result stays unchanged. Synthetic preview notes remain illustrative and are not sent to the service.

Exercise a normal and a positive permitted source recording, corrupt/oversized input, wrong credentials, the longest allowed clip, and concurrent submissions. Record model errors honestly. Never substitute known labels for predictions or hide unsuccessful jobs from performance metrics.
